# 지역 지침서 뼈대

해당 없는 절은 통째로 지운다. 절 순서는 "Claude가 가장 먼저 알아야 하는 것" 순이다.
꺾쇠 안은 채울 자리다. 실제 파일에는 꺾쇠를 남기지 않는다.

````markdown
# CLAUDE.md — <폴더 이름>

> 지역 지침. 전역 지침(~/.claude/CLAUDE.md)과 충돌하면 이 파일이 우선한다.

## 이 폴더는
<무엇을 위한 폴더인지 1~2줄. 결과물을 누가 보는지.>

## 명령어
```bash
<설치 명령>
<실행 명령>
<테스트 명령>
```

## 구조
| 경로 | 역할 |
|---|---|
| `<폴더>/` | <한 줄> |

## 규칙
- <이 폴더에만 해당하는 규칙> — <이유가 안 보이면 짧은 이유>
- 전역의 <X> 대신 이 폴더는 <Y>.

## 건드리지 않는 것
- `<경로>` — <이유>

## 주의
- <이 폴더에서 실제로 겪었거나 README에 적힌 함정>
````

## 유형별로 추가하면 좋은 절

| 유형 | 절 | 예시 |
|---|---|---|
| 코드 | `## 버전` | Python 3.11 (conda `py311`), Spring Boot 3.3, React 19 |
| 코드 | `## 커밋` | `type(scope): 한국어 제목`, 실제 로그에서 본 형식 |
| 문서 | `## 문체·용어` | "~한다" 체, 용어집 위치, 금지 표현 |
| 문서 | `## 산출 형식` | 최종본은 `.docx`, 이미지 폭 15cm, 파일명 `YYYYMMDD_제목_v2` |
| 수업 | `## 이름 규칙` | 폴더 `YYMMDD_n_주제`, 파일 `vNN_NN_주제.py`, 빈 파일은 다음 수업 자리표시 |
| 데이터·ML | `## 데이터` | 원본 위치(읽기 전용), 가공본 위치, 대용량은 `.gitignore` |
| 모노레포 | `## 하위 지침` | `frontend/CLAUDE.md`, `backend/CLAUDE.md`가 따로 있음 |

## 예시 1 — 코드 저장소 (React + Vite)

````markdown
# CLAUDE.md — stock-dashboard-frontend

> 지역 지침. 전역 지침과 충돌하면 이 파일이 우선한다.

## 이 폴더는
주식 대시보드 프론트엔드. 백엔드는 `../stock-dashboard-backend`(포트 8080).

## 명령어
```bash
npm install
npm run dev      # http://localhost:5173
npm run lint
npm run build
```

## 구조
| 경로 | 역할 |
|---|---|
| `src/pages/` | 라우트 단위 화면 |
| `src/components/` | 재사용 컴포넌트 (페이지 전용은 페이지 폴더 안에) |
| `src/api/` | axios 인스턴스와 API 함수. 컴포넌트에서 axios 직접 호출 금지 |

## 규칙
- API 기본 주소는 `import.meta.env.VITE_API_URL`. 하드코딩 금지.
- 새 라이브러리는 추가 전에 제안만 한다 — 번들 크기를 관리 중.
- 커밋 전 `npm run lint` 통과.

## 건드리지 않는 것
- `dist/` — 빌드 산출물
- `.env.local` — 개인 설정, 커밋 금지
````

## 예시 2 — 문서 폴더

````markdown
# CLAUDE.md — 2026 사업계획서

## 이 폴더는
지원사업 제출용 사업계획서 작업 폴더. 최종본은 심사위원이 읽는다.

## 구조
| 경로 | 역할 |
|---|---|
| `원고/` | 장별 마크다운 원고 (`01_개요.md` …) |
| `자료/` | 통계·인용 원문. 읽기만 한다 |
| `제출본/` | 최종 `.docx`. 사람이 직접 만든다 |

## 규칙
- 문체는 "~함/~임" 개조식. 공고문 양식 순서를 바꾸지 않는다.
- 수치에는 출처(`자료/` 파일명)를 각주로 단다 — 심사에서 근거를 확인한다.
- 장 하나는 A4 2쪽(약 1,800자) 이내.

## 건드리지 않는 것
- `자료/`, `제출본/`
````
