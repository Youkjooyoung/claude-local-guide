# 유형별 사실 수집 체크리스트

전부 확인할 필요는 없다. 지침에 넣을 가치가 있는 사실이 나오는 항목만 본다. 못 찾은 항목은 지침에 넣지 않는다.

## 공통 (모든 유형)
| 볼 것 | 어디서 | 지침에 넣는 경우 |
|---|---|---|
| 폴더 목적 | README 첫 문단, 폴더 이름 | 항상 1~2줄 |
| 최상위 구조 | `ls`, 2단계까지 | 폴더가 3개 이상일 때 |
| 이름 규칙 | 파일·폴더 이름 샘플 5~10개 | 일정한 패턴이 보일 때 |
| `.gitignore` | 루트 | 무엇을 올리지 않는지가 비직관적일 때 |
| 별도 저장소 | 하위 폴더의 `.git` (`find . -name .git -maxdepth 3`) | 있으면 반드시 — 상위 저장소에 섞이면 사고 |
| 커밋 형식 | `git log --oneline -20` | 전역과 다를 때만 |
| 비밀값 파일 | `.env*`, `*.pem`, `*key*`, `credentials*` | 위치와 "커밋 금지"만. 값은 절대 옮기지 않음 |
| 주의사항 | README의 주의·Known issues, `TODO`/`FIXME` 주석 | 실제로 Claude가 걸려 넘어질 만한 것 |

## 코드
| 볼 것 | 어디서 |
|---|---|
| 실행·테스트·빌드 명령 | `package.json` `scripts`, `Makefile`, `pom.xml`/`build.gradle`, `pyproject.toml` `[tool.*]`, README |
| 언어·프레임워크 버전 | `package.json`, `pom.xml`, `.python-version`, `pyproject.toml`, `environment.yml` |
| 환경 | conda 환경 이름, 가상환경 경로, 필요한 서비스(DB, Redis)와 포트 |
| 린트·포맷터 | `.eslintrc*`, `.prettierrc`, `ruff.toml`, `checkstyle.xml` — 있으면 "커밋 전 실행"으로 |
| 패키지 구조 | 소스 루트 아래 2단계. 레이어 규칙(controller → service → repository 등)이 보이면 한 줄로 |
| 생성물 | `dist/`, `build/`, `target/`, `node_modules/`, `__pycache__/` — 보통 `.gitignore`에 있으면 생략 |
